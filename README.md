## 和别家不一样在哪

同类的拼餐项目，大多做到**餐品级**——挑几个菜名，算个总价。
这个往下钻一层，做**轮次级**：选套餐里的**每一轮**。

| | 多数项目 | 这里 |
|---|---|---|
| 选择粒度 | 选整份套餐 | **选套餐里每一轮**（主食/小食/饮料各自选） |
| 忌口判定 | 菜名关键词猜 | 读官方 `choices`，**逐轮判定** |
| 套餐内优化 | 无 | 解析 `diffPrice`，**自动挑负差价** |
| 约束无解 | 硬凑 | **必选轮次全违规则整份弃用** |
| 当季活动 | 无 | `campaign-calendar` **自动识别限定品** |
| AA 分账 | 常缺 | **整数分运算，零尾差** |
| 没验证的 | 默认"不辣" | 标 `辣味未确认`，**不下结论** |

**① 忌口做到轮次级**
`人气经典随心配`（¥14.9）蓝区 8 个官方候选里，不辣的有双牛堡/麦香鱼/椒盐鸡排，含鸡的有麦香鸡/麦乐鸡——**每人从官方合法选项里挑**。关键词只能告诉你"这套餐叫板烧鸡腿堡"，轮次级能告诉你"它里面主食还能换麦香鱼"。

**② 必选轮次无解，整份弃用**
`全明星双人分享餐`（¥49.9）的"选择汉堡"轮只有 `麦辣鸡腿汉堡` 和 `酥酥多笋卷`——**两个都辣**。对不吃辣的人整份不可用，直接弃用退档，而不是端上去再解释"可能有点辣"。

**③ 读懂 `diffPrice`，套餐省 15.5 元**
`巨无霸三件套`（¥37.5）小食轮里 `小杯玉米杯` 差价 **−¥1**，比默认中薯条还便宜。

- 巨无霸单品 ¥26.5 + 脆脆薯条 ¥16 + 可乐 ¥9.5 = **¥52.0**
- 巨无霸三件套（配小杯玉米杯）= **¥36.5** → **省 15.5 元**

只看餐品价格，算不出这一层。

## 跟着当季活动走

麦当劳的活动话术会渗进菜单名：活动叫「就「酱」心有所「薯」」，菜单就多个「鸡薯双全盒」；活动叫「“韩”风刮到了四件套」，菜单就多一整个「龙焰鸡腿堡」系列。

所以会拉 `campaign-calendar` 对上号。2026-10-10 识别出龙焰鸡腿堡三件套、龙焰芝士棒鸡腿堡、蓝莓爆爆珠麦旋风、灰焰圆筒、鸡薯双全盒等 7 项，还能抽出营销话术和谐音梗落点（`就「酱」心有所「薯」` → `['酱','薯']`）。

**设计成活动无关**——不写死世界杯或春节，换任何联名节庆都自动生效。

## 分账：零尾差

浮点数在钱上不靠谱，`13.9 / 3 = 4.6333...`，四舍五入后经常差几分。
这里**全程整数分**运算，余数按序分配：10 元分 3 人 = `334/333/333`。

```
A  应付 ¥24.15
    ¥13.90  人气经典随心配
    ¥15.90  鸡薯双全盒 ×2（共享）
    -¥5.70  整单优惠均摊
合计   ¥96.60   人均 ¥24.15
校验   ✅ 零尾差，合计与实付分毫不差
```

## 装

**1. 拿 Token** —— [open.mcd.cn/mcp](https://open.mcd.cn/mcp) → 手机号登录 → 控制台 → 激活

**2. 配连接器** —— WorkBuddy【连接器】→ 自定义连接器 → 配置 MCP：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamableHttp",
      "url": "https://mcp.mcd.cn",
      "headers": { "Authorization": "Bearer YOUR_MCP_TOKEN" }
    }
  }
}
```

> 改完配置**要重启客户端**。🔒 Token 只放本地，本仓库的 `mcp-config.example.json` 只有 `${MCD_MCP_TOKEN}` 占位符。

**3. 用起来** —— 把 `SKILL.md` 和 `scripts/` 交给你的 Agent。
依赖：**Python 3.9+，仅标准库**，无需 pip install。

命令行也能跑：

```bash
python scripts/plan.py data/sample-case-4p-180.json > plans.json
python scripts/campaign.py data/sample-campaigns.json data/sample-case-4p-180.json plans.json
python scripts/render.py plans.json text
python scripts/split_bill.py plans.json value
```

全离线，不联网、不要 Token。

## 边界（先看这段）

- ⚠️ **辣味是名称与标签的关键词判定**，麦当劳没有成分表或过敏原字段。**不构成过敏建议。**
- ⚠️ 没拉过详情的套餐标「**辣度未确认**」，而不是默认不辣。点单时自己看一眼。
- ⚠️ **券是动态的**。实测该店 10/10 当天无券（卡包 13 张全绑了别的日期）。"今天有没有券"每次现场查。
- ⚠️ **不下单**。只到核价为止。
- ⚠️ 价格与供应以麦当劳官方渠道实时结果为准。
